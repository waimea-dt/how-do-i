## JS only

No HTML block provided. Default HTML should be inserted automatically.

<web-playground data-height="16em">

```js
const heading = document.querySelector('h1')
const paragraph = document.querySelector('p')

if (heading) heading.textContent = 'Hello, World! (updated by JS)'
if (paragraph) paragraph.textContent = 'This is a test page. JavaScript is now controlling this content.'

const btn = document.createElement('button')
btn.type = 'button'
btn.textContent = 'Increment: 0'
btn.style.cssText = 'margin: 1rem 0 0 0; padding: 0.45rem 0.7rem; border-radius: 0.4rem; border: 1px solid #1d4ed8; background: #eff6ff; cursor: pointer;'

let count = 0
btn.addEventListener('click', () => {
    count += 1
    btn.textContent = `Increment: ${count}`
})

document.body.appendChild(btn)
```

</web-playground>

## CSS + JS (no HTML block)

Default HTML is injected.

<web-playground data-height="18em">

```css
body {
    margin: 0;
    font-family: system-ui, sans-serif;
    background: linear-gradient(150deg, #e0f2fe, #f0fdf4);
}

.widget {
    max-width: 36rem;
    margin: 1rem auto;
    padding: 1rem;
    border: 2px solid #0f766e;
    border-radius: 0.7rem;
    background: #ffffff;
}

.widget h2 {
    margin-top: 0;
}

.widget button {
    border: 1px solid #0f766e;
    background: #ccfbf1;
    color: #134e4a;
    border-radius: 0.4rem;
    padding: 0.35rem 0.65rem;
    cursor: pointer;
}
```

```js
const panel = document.createElement('main')
panel.className = 'widget'

const title = document.createElement('h2')
title.textContent = 'CSS + JS (No HTML Block)'

const text = document.createElement('p')
text.textContent = 'All visible content is created by JavaScript.'

const button = document.createElement('button')
button.type = 'button'
button.textContent = 'Spawn message'

const list = document.createElement('ul')
let count = 1

button.addEventListener('click', () => {
    const item = document.createElement('li')
    item.textContent = `Dynamic line ${count}`
    list.appendChild(item)
    count += 1
})

panel.append(title, text, button, list)
document.body.appendChild(panel)
```

</web-playground>

## Hidden / non-visible content

This demo has HTML that is hidden by CSS (`display: none`).
Edit CSS to reveal it.

<web-playground data-height="16em">

```html
<main>
    <!-- This section is hidden by CSS but still editable in HTML pane -->
    <section class="hidden-panel">
        <h3>Hidden Content</h3>
        <p>If you remove the CSS rule, this appears.</p>
    </section>

    <section class="visible-panel">
        <h3>Visible Content</h3>
        <p>Edit CSS or HTML to reveal the hidden panel.</p>
    </section>
</main>
```

```css
body {
    font-family: system-ui, sans-serif;
    margin: 0;
    padding: 1rem;
}

.hidden-panel {
    display: none;
}

.visible-panel {
    border: 2px dashed #2563eb;
    border-radius: 0.6rem;
    padding: 0.8rem;
    background: #eff6ff;
}
```

</web-playground>

## Hidden Setup Code (id= and depends=)

Like Python and SQL runners, you can hide boilerplate code using `id=NAME` blocks.
Student code uses `depends=NAME` to reference the hidden setup.

The editors only show the `depends=` blocks, but the preview includes both hidden + visible code.

<web-playground data-height="25em">

```html id=base
<header class="app-header">
    <h1>My Demo App</h1>
</header>
```

```css id=base
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

body {
    min-height: 100vh;
    display: flex;
    flex-direction: column;
    font-family: system-ui, sans-serif;
}

.app-header {
    background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
    color: white;
    padding: 1.5rem;
    box-shadow: 0 4px 6px rgba(0,0,0,0.1);
}

.app-header h1 {
    font-size: 1.5rem;
    font-weight: 600;
}
```

```js id=base
const API_KEY = "demo-12345";
console.log("App initialized with API key:", API_KEY);
```

```html depends=base
<main class="content">
    <p>Student focuses on this main content area.</p>
    <p>The header and base styles are hidden!</p>
</main>
```

```css depends=base
.content {
    flex: 1;
    padding: 2rem;
    background: #f3f4f6;
}

.content p {
    margin-bottom: 1rem;
    font-size: 1.1rem;
    color: #374151;
}
```

```js depends=base
document.querySelector('.content').addEventListener('click', () => {
    alert('Content clicked! API Key: ' + API_KEY);
});
```

</web-playground>

> **Note:** The editors above only show the `depends=base` blocks, but if you inspect the preview or check the console, you'll see the hidden base code is included!
