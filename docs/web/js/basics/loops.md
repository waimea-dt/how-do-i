# Loops

Loops run repeated actions.

## for loop

```js
for (let i = 1; i <= 5; i++) {
    console.log(`Round ${i}`)
}
```

## loop through array

```js
const topics = ['HTML', 'CSS', 'JS']

for (const topic of topics) {
    console.log(topic)
}
```

Use loops to render lists, process scores, or validate multiple inputs.
