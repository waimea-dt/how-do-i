# Variables and Types

Use `const` for values that do not change.
Use `let` for values that do change.

```js
const studentName = 'Mika'
let score = 0
score = score + 10
```

## Common types

- string: text
- number: numeric values
- boolean: true or false
- array: ordered list
- object: grouped key-value data

```js
const player = {
    username: 'Nova',
    level: 3,
    isOnline: true
}
```
