# Conditional Logic

Conditionals let code choose between actions.

```js
const mark = 78

if (mark >= 80) {
    console.log('Excellence')
} else if (mark >= 65) {
    console.log('Merit')
} else if (mark >= 50) {
    console.log('Achieved')
} else {
    console.log('Not Achieved')
}
```

## Logical operators

- `&&` and
- `||` or
- `!` not
