# Accessibility Checklist Recipe

Use this checklist before submitting project.

## Structure

- one clear `<h1>` per page
- heading levels in order
- semantic landmarks: `header`, `nav`, `main`, `footer`

## Text and Colour

- body text high contrast
- links clearly visible
- no information only by colour

## Forms

- all controls have `<label>`
- validation messages clear and specific
- keyboard tab order makes sense

## Keyboard and Motion

- interactive elements reachable by keyboard
- visible focus state
- animations subtle and not required to use site

## Images

- useful alt text on informative images
- empty alt (`alt=""`) on decorative images

This checklist is simple evidence of quality and care for L2/L3 assessment.
