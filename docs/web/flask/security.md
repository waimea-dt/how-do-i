# What is Security?

Web security is protecting users and system from misuse, data leaks, and attacks.

## Security basics for school projects

- never store plain text passwords
- validate all user input
- protect session cookies
- avoid exposing secret keys
- show safe error messages

## Common threats

- weak passwords
- SQL injection
- cross-site scripting (XSS)
- session hijacking

Security should be part of design from start, not added at end.
