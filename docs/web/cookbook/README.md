# Cookbook

A collection of useful snippets, templates, and patterns for web development. These are ready-to-use solutions for common problems you'll encounter when building webpages.

> [!TIP]
> These snippets are designed to be copied and adapted. Each page explains what it does and how to customise it.

## Cookbook Categories

- project starters
- front-end UI patterns
- Flask and Jinja server-side patterns
- HTMX dynamic update patterns
- Docker deployment starters
- accessibility quality checks

## Suggested Use

1. pick one recipe to solve immediate problem
2. copy minimal code version first
3. test in small demo page
4. adapt naming and styling to your project
5. document what you changed and why
