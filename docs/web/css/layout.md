# Layout Properties

Layout properties control element flow and alignment.

```css
.wrapper {
    max-width: 70rem;
    margin: 0 auto;
    padding: 1rem;
}

.section {
    display: block;
}
```

## Common layout tools

- `display`
- `width`, `max-width`
- `margin: 0 auto` for centring blocks
- `overflow` for clipped content
