# Text Properties

Typography affects usability and quality.

```css
body {
    font-family: 'Segoe UI', sans-serif;
    font-size: 1rem;
    line-height: 1.6;
}

h1 {
    font-size: 2rem;
    letter-spacing: 0.02em;
}
```

## Good practice

- body text should be easy to scan
- use consistent heading scale
- avoid low contrast text colours
