# CSS Properties

A CSS rule has selector plus properties.

```css
.card {
    background: white;
    color: #1f2937;
    padding: 1rem;
    border-radius: 0.75rem;
}
```

## Property groups

- text: font, size, line-height, alignment
- box model: margin, border, padding
- layout: display, flex, grid, position
- visual effects: shadow, opacity, transform
