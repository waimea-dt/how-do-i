# Position Properties

Use positioning for controlled element placement.

```css
.badge {
    position: absolute;
    top: 0.5rem;
    right: 0.5rem;
}

.card {
    position: relative;
}
```

## Position values

- `static`: default
- `relative`: offset from normal position
- `absolute`: positioned inside nearest positioned parent
- `fixed`: pinned to viewport
- `sticky`: sticks after scroll threshold
