# CSS Selectors

Selectors choose which HTML elements receive styles.

```css
h1 {
    color: #2244aa;
}

.notice {
    background: #eef6ff;
}

#main-nav {
    border-bottom: 2px solid #2244aa;
}
```

## Useful selectors

- element: `p`
- class: `.card`
- id: `#header`
- descendant: `.menu a`
- pseudo-class: `a:hover`
