# Jinja

<speak>

![Mac](../../_assets/macs/macintosh-idea.svg)

Write it once, use it everywhere!

**Jinja** lets Flask build HTML pages from templates and data.

</speak>


Jinja mixes normal HTML with data from Python, so you can define a page's structure once and reuse it across your whole site. These notes cover Jinja's syntax, working with data, and keeping your templates safe.
