# HTML Document Structure

Every HTML page should follow standard structure so browser, tools, and screen readers can understand it.

## Starter Template

```html
<!doctype html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Study Hub</title>
</head>
<body>
    <h1>Welcome</h1>
</body>
</html>
```

## Why each part matters

- `<!doctype html>`: tells browser to use modern HTML rules
- `<html lang="en">`: sets page language for accessibility
- `<meta charset="UTF-8">`: supports full text character set
- `<meta name="viewport">`: makes layout scale on mobile
- `<title>`: appears in tab and search results

## L2/L3 checkpoint

Use this structure on every assessed page. Missing viewport or language tags is common quality issue.
