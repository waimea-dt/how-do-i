# Semantic HTML

Semantic tags describe meaning, not only appearance.

## Common semantic elements

- `<header>`: top banner area
- `<nav>`: main site navigation
- `<main>`: main page content
- `<section>`: grouped topic block
- `<article>`: standalone piece of content
- `<footer>`: bottom page information

## Example

```html
<body>
    <header>
        <h1>Game Strategy Notes</h1>
    </header>

    <nav>
        <a href="/">Home</a>
        <a href="/guides">Guides</a>
    </nav>

    <main>
        <section>
            <h2>Latest Tips</h2>
            <article>
                <h3>Speedrun Route</h3>
                <p>Use checkpoints to save time.</p>
            </article>
        </section>
    </main>

    <footer>Created by L3 DT students</footer>
</body>
```

Semantic structure improves accessibility and helps markers see clear page organisation.
