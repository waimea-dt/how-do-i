# Page Structure Blocks

Most pages are made from reusable blocks.

## Typical layout blocks

- Header: branding and page title
- Navigation: site links
- Main: primary content
- Aside: related notes
- Footer: credits or legal info

## Example

```html
<body>
    <header>Study Site</header>
    <nav>Main links</nav>
    <main>
        <section>
            <h2>Topic</h2>
            <p>Core explanation.</p>
        </section>
    </main>
    <footer>2026 DT class</footer>
</body>
```
