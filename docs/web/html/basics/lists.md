# Adding Lists

Lists are useful for steps, features, and grouped notes.

## Unordered list

```html
<ul>
    <li>HTML structure</li>
    <li>CSS styling</li>
    <li>JavaScript interactivity</li>
</ul>
```

## Ordered list

```html
<ol>
    <li>Plan page</li>
    <li>Build content</li>
    <li>Test and improve</li>
</ol>
```

Use ordered list when order matters.
