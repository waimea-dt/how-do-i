# Adding Links

Links connect pages and resources.

## Page link

```html
<a href="/web/css/">Learn CSS</a>
```

## External link

```html
<a href="https://developer.mozilla.org" target="_blank" rel="noopener">
    MDN Web Docs
</a>
```

## Navigation example

```html
<nav>
    <a href="/">Home</a>
    <a href="/about">About</a>
    <a href="/contact">Contact</a>
</nav>
```
