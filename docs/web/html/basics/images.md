# Adding Images

Images add context and visual explanation.

## Basic image

```html
<img src="images/network-topology.png" alt="Simple network topology diagram">
```

## Responsive image style

```css
img {
    max-width: 100%;
    height: auto;
}
```

## Figure with caption

```html
<figure>
    <img src="images/wireframe.png" alt="Low-fidelity homepage wireframe">
    <figcaption>Wireframe used during design planning</figcaption>
</figure>
```
