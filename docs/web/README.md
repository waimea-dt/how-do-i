# Web Development

Web development is about building websites and web apps that people can use on phones, tablets, and computers.

At NZ Digital Technologies Level 2 and Level 3, you are expected to understand both:

- front-end development: what users see and click
- back-end development: what server does behind scenes

This section gives a complete pathway through core web technologies used in school projects:

- HTML for structure
- CSS for styling and layout
- JavaScript for interactivity
- Flask for server-side logic
- Jinja for templates
- HTMX for dynamic page updates
- Docker for packaging and deployment

## Suggested Learning Order

1. Start with [Front-End Web Development](web/front-end.md)
2. Work through HTML, then CSS, then JavaScript
3. Move to [Back-End Web Development](web/back-end.md)
4. Learn Flask, then Jinja, then HTMX
5. Finish with Docker and cookbook tasks

## Assessment Focus (L2/L3)
