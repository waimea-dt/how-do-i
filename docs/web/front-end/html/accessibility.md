# Accessible HTML

Accessible HTML means more learners can use your website, including keyboard and screen-reader users.

## Essentials

- Use semantic tags (`main`, `nav`, `header`)
- Add meaningful alt text for informative images
- Keep heading order logical (`h1` then `h2`)
- Ensure form controls have labels
- Use descriptive link text

## Good and bad link text

Bad:

```html
<a href="/guide">Click here</a>
```

Good:

```html
<a href="/guide">Read full cyber safety guide</a>
```

## Alt text rule

Describe purpose, not file name.

```html
<img src="cpu.png" alt="Diagram showing CPU, RAM, and storage connections">
```
