 # Why Use Docker?

Docker solves "works on my machine" problems by packaging app with its runtime and dependencies.

## Benefits for school projects

- Same setup for every team member
- Fast onboarding on new device
- Safer deployment to server
- Clear, repeatable run commands

## Example scenario

Without Docker:

- one student uses Python 3.10
- another uses Python 3.12
- package versions mismatch
- app fails differently on each machine

With Docker:

- both run same image
- app behaviour stays consistent
