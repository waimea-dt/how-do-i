## Encryption Basics Quiz

- # What problem does encryption solve?

    ---

    - [ ] It compresses data so it transfers and downloads faster
    - [x] It scrambles data so only authorised people can read it
    - [ ] It backs up data automatically in case of a crash
    - [ ] It speeds up network connections so pages load faster

    ---

    - [x] **Correct!** Encryption's core job is confidentiality - hiding data from anyone except the intended recipient.
    - [ ] **Not quite.** Encryption doesn't reduce file size or speed up networks - it scrambles data for security.

- # In cryptography, who is "Eve"?

    ---

    - [ ] The person who sends the original message
    - [ ] The person who receives the decrypted message
    - [x] Someone eavesdropping on the communication channel
    - [ ] The algorithm used to encrypt the message

    ---

    - [x] **Correct!** Alice sends, Bob receives, and Eve represents anyone trying to intercept or spy on the message.
    - [ ] **Try again.** Alice is the sender and Bob is the receiver - Eve is the eavesdropper.

- # Which of these is an example of an "integrity" check, not confidentiality?

    ---

    - [ ] Encrypting a text message so nobody else can read it
    - [x] Checking a downloaded file's hash matches the published hash
    - [ ] Connecting to a VPN before browsing the web
    - [ ] Storing your passwords inside a password manager

    ---

    - [x] **Correct!** Integrity is about proving data hasn't been tampered with - hash checks are a classic example.
    - [ ] **Not quite.** That option relates to confidentiality or convenience, not proving data is unchanged.

- # Why did the Enigma machine's daily-changing settings make it so hard to crack?

    ---

    - [ ] Because it relied on a public key system nobody could intercept
    - [x] Because it created a huge number of possible settings that couldn't be tried by hand
    - [ ] Because it was a purely mechanical device that used no electricity at all
    - [ ] Because it hashed every message instead of using substitution

    ---

    - [x] **Correct!** Enigma's rotors and plugboard combined to create more possible settings than could ever be tried manually.
    - [ ] **Not quite.** Enigma predates public key cryptography and used electromechanical substitution, not hashing.

- # For the 2026 assessment, what should impact-based answers focus on?

    ---

    - [ ] The exact mathematics and formulas behind each algorithm
    - [x] Human factors and social impact - who is affected and why
    - [ ] Memorising the exact key length of every historical cipher
    - [ ] The programming languages used to implement each algorithm

    ---

    - [x] **Correct!** 2026 questions focus on human factors and social impact, not just the technical maths.
    - [ ] **Not quite.** While useful background, the assessment specifically wants human and social impact reasoning.
