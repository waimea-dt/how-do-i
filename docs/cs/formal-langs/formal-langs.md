# What is a Formal Language?

A **formal language** is a set of strings built from a fixed **alphabet**, using precise rules called a **grammar**. Unlike natural languages (like English), formal languages have no ambiguity - every valid string can be checked mechanically, which is exactly what a computer needs to be able to do.

Programming languages, regular expressions, and even simple things like phone numbers or email addresses are all examples of formal languages - a computer can check whether some text belongs to the language, without needing to "understand" it the way a person does.
