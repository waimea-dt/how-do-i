# Formal Languages

<speak>

![Mac](../../_assets/macs/macintosh-idea.svg)

Does not compute... wait, yes it does!

**Formal Languages** describes the precise rules that let a computer understand structured text.

</speak>


Programming languages, regular expressions, and even simple validation rules all rely on formal languages - a set of precise, unambiguous rules that a computer can check mechanically. These notes cover how formal languages are defined, and how computers use them to parse and understand structured text.
