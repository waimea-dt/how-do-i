# What is Scratch?

**Scratch** is a beginner-friendly, block-based programming language created by MIT. Instead of typing code, you snap together coloured blocks like puzzle pieces to build programs - perfect for learning how programs work without worrying about typos or syntax errors.

Scratch is great for building simple games, animations and interactive stories, and the ideas you learn (loops, conditions, variables) carry over directly into text-based languages like Python and Kotlin.
