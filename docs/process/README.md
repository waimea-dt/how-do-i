# The Design Process

<speak>

![Mac](../_assets/macs/macintosh-idea.svg)

Plan first, build second!

**The Design Process** is a structured way to turn a problem into a working solution.

</speak>


Good products don't happen by accident - they follow a structured process of research, design, building, and testing, repeated until the solution works well for the people using it. These notes cover each stage of that process, and how to document your work along the way.
