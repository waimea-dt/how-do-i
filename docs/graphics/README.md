# Graphics & Images

Graphics and images are essential elements in digital design, from websites and apps to games and multimedia projects. Understanding image formats, editing tools, and design principles helps create effective visual content.

> [!TIP]
> Use the sidebar to navigate the topics in this guide. If you're new to digital graphics, start with **Graphics Basics** and work through the sections in order.

## Why Learn About Graphics?

- **Visual Communication** - images convey information quickly and effectively
- **Brand Identity** - consistent graphics strengthen recognition and trust
- **User Experience** - well-chosen images enhance usability and engagement
- **Technical Skills** - understanding formats and optimization improves performance
- **Creative Expression** - graphics tools enable artistic and design work

> [!NOTE]
> Digital graphics come in two main types: raster (pixel-based) and vector (path-based). Each has different uses, strengths, and file formats. Modern projects often use both types together.
