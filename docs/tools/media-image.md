## Icon Collections

- [Lucide Icons](https://lucide.dev/)
    - **Recommended**
    - Huge collection of icons
    - Clean and modern style
    - Free to use

- [Font Awesome](https://fontawesome.com/)
    - Popular icon library
    - Free version available
    - Easy to use in web projects

- [Heroicons](https://heroicons.com/)
    - Beautiful hand-crafted icons
    - Made by Tailwind CSS team
    - Free and open-source

- [Flaticon](https://www.flaticon.com/)
    - Huge icon collection
    - Many styles
    - Free with attribution


## Illustrations and Graphics

- [The Noun Project](https://nounproject.com)
    - Huge collection of graphics
    - Simple and clear icons
    - Free with attribution

- [unDraw](https://undraw.co/)
    - **Great for web projects**
    - Open-source illustrations
    - Customisable colours
    - Free to use

- [DrawKit](https://drawkit.com/)
    - Free vector illustrations
    - Good quality
    - Various styles


## Photo Libraries

- [Unsplash](https://unsplash.com/)
    - **Recommended**
    - Huge collection of high-quality images
    - Free to use
    - No attribution required

- [Pexels](https://www.pexels.com/)
    - Collection of images and videos
    - Free to use
    - Good search features

- [Pixabay](https://pixabay.com/)
    - Images, videos, music
    - Free to use
    - No attribution required

- [StockSnap](https://stocksnap.io/)
    - Categorised collection
    - Free to use
    - High resolution

- [ReShot](https://www.reshot.com/)
    - Free illustrations and icons
    - Unique style
    - No attribution required
