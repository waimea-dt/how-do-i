# Database Management and Editing Tools

<!-- tool-lists -->

## SQLite Tools

- [DB Browser for SQLite](https://sqlitebrowser.org/)
    - **Recommended**
    - Visual database editor
    - Create, edit and query SQLite databases
    - Free and open-source
    - Cross-platform

- [SQLite Studio](https://sqlitestudio.pl/)
    - Feature-rich SQLite manager
    - Import/export data
    - Free and open-source


## General Database Tools

- [DBeaver Community Edition](https://dbeaver.io/)
    - Universal database tool
    - Supports SQLite, MySQL, PostgreSQL, etc.
    - Visual query builder
    - Free and open-source

- [HeidiSQL](https://www.heidisql.com/)
    - Lightweight database manager
    - Good for MySQL and SQLite
    - Free and open-source
