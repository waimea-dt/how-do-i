# Colour Palette Tools

## Colour Palettes

- [Reasonable Colors](https://reasonable.work/colors/#colors)
    - Sets of colours that work well

- [Material Design Colour Palettes](https://materialui.co)
    - Colour schemes from the Google Material Design system

- [Material Palette](https://www.materialpalette.com)
    - Material Design colour palette picker

- [Khroma](https://www.khroma.co)
    - Uses AI to come up with pleasing palettes

- [Coolors](https://coolors.co)
    - Palette generator that can use a variety of schemes

- [Color Hunt](https://colorhunt.co)
    - Lots of palettes

- [Adobe Color](https://color.adobe.com)
    - Lots of example palettes
    - Can extract colours from an image
    - Can be hard to use well


## Colour Applied to a Design

- [RealtimeColors](https://realtimecolors.com)
    - **Recommended**
    - Manipulate the colour of a 'real' website in real-time
    - See [this video](https://www.youtube.com/watch?v=HAlIWRcldoc) for info and how to use
