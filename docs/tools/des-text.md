## Font Selection

- [Google Fonts](https://fonts.google.com/)
    - Huge collection
    - Easy to use in sites via CSS import

- [Font Preview](https://fontprev.com/)
    - View combinations of Google fonts
    - Font list is styled as the font, and has filters, so easy to pick
    - Can replace fonts on an external site

- [Google Font Pair Finder](https://10015.io/tools/google-fonts-pair-finder)
    - Can preview pairs of Google fonts in a variety of fake formats

- [Type Scale](https://typescale.com/)
    - Allows experimentation with font sizing, line height, etc.
