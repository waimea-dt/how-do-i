# Online Database Tools and Playgrounds

<!-- tool-lists -->

## SQL Practice and Learning

- [SQLite Online](https://sqliteonline.com/)
    - **Recommended for quick tests**
    - Run SQL queries in browser
    - No account needed
    - Supports SQLite

- [SQL Fiddle](http://sqlfiddle.com/)
    - Test SQL queries online
    - Multiple database engines
    - Share queries with others

- [DB Fiddle](https://www.db-fiddle.com/)
    - Modern SQL playground
    - Clean interface
    - Multiple database support


## SQL Learning Tools

- [SQLZoo](https://sqlzoo.net/)
    - Interactive SQL tutorials
    - Learn by doing
    - Good for beginners

- [SQL Bolt](https://sqlbolt.com/)
    - Step-by-step SQL lessons
    - Interactive exercises
    - Clear explanations
