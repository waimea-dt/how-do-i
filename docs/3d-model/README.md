# 3D Modelling

3D modelling is the process of creating three-dimensional representations of objects using specialized software. These models are used in games, films, architecture, product design, and many other fields.

> [!TIP]
> Use the sidebar to navigate the topics in this guide. If you're new to 3D modelling, start with **3D Basics** and work through the sections in order.

## Why Learn 3D Modelling?

- **Visualization** - brings ideas and concepts to life in three dimensions
- **Game Development** - creates characters, environments, and objects for games
- **Animation & Film** - builds assets for animated movies and visual effects
- **Product Design** - prototypes and tests designs before manufacturing
- **Architecture** - visualizes buildings and spaces before construction
- **Career Skills** - 3D artists are in demand across creative and technical industries

> [!NOTE]
> Popular 3D software includes Blender (free and open-source), Maya, 3ds Max, and Cinema 4D. Many game engines like Unity and Unreal Engine also include 3D modelling capabilities.
